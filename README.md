# Weather Bot

A Telegram bot that predicts the weather using OpenWeatherMap and recommends clothing based on temperature, wind, and rain. Clothing suggestions are generated by a CNN trained on the Fashion MNIST dataset.

## Features
- **Weather forecast** — temperature, wind speed, cloud cover, and rain probability for the next 0–5 days
- **Clothing recognition** — CNN trained on Fashion MNIST (10 classes: t-shirts, trousers, sweaters, dresses, coats, sandals, shirts, sneakers, bags, boots)
- **Smart outfit suggestions** — picks clothing items based on weather conditions:
  - < 0°C → coat, sweater, boots
  - 0–10°C → coat or thick jumper, sweater, boots
  - 10–20°C → light jumper, sneakers, sweater
  - \> 20°C → t-shirt, sandals, shorts
  - Wind > 30 m/s → jacket warning
  - Rain → umbrella / waterproof recommendation
- **Visual output** — sends a generated image with three clothing items

## Prerequisites
1. Install the required libraries:
```bash
pip install aiogram pyowm tensorflow keras matplotlib numpy pandas tqdm pillow
```
2. Get an **OpenWeatherMap API key**: [openweathermap.org/api](https://openweathermap.org/api)
3. Get a **Telegram Bot token** from [@BotFather](https://t.me/BotFather)

## Setup
1. Replace `YOUR API` placeholders in the code:
   - `OWM('YOUR API')` — OpenWeatherMap key
   - `Bot(token='YOUR API')` — Telegram bot token
2. Add the cities you want the bot to use in the `et` list:
```python
et = ['Tyumen', 'Moscow', 'Saint Petersburg']  # add your cities
```
3. **First run — train the model**: uncomment the training block (lines with `model.compile` and `model.fit`) and comment out the `load_model` line. After training, revert everything back.
4. **Subsequent runs — load the trained model**: keep `model = keras.models.load_model("my_model.keras")` uncommented.

## Model Architecture
```
Conv2D(64, 5×5, relu, same) → MaxPool(2×2)
Conv2D(128, 5×5, relu, same) → MaxPool(2×2)
Conv2D(256, 5×5, relu, same) → MaxPool(2×2)
Flatten → Dense(256, relu) → Dense(10, softmax)
```
- **Optimizer:** Adam (lr=1e-3)
- **Loss:** sparse_categorical_crossentropy
- **Epochs:** 10
- **Validation split:** 33%
- **Accuracy:** ~82%

## Bot Flow
```
/start → "начать" → select city → select days (0–5)
         → weather description + clothing recommendations → "наряд" → image
```

# Weather Bot

Telegram-бот, который предсказывает погоду через OpenWeatherMap и рекомендует одежду в зависимости от температуры, ветра и осадков. Подбор одежды выполняется с помощью свёрточной нейросети, обученной на датасете Fashion MNIST.

## Возможности
- **Прогноз погоды** — температура, скорость ветра, облачность и вероятность осадков на 0–5 дней вперёд
- **Распознавание одежды** — CNN на Fashion MNIST (10 классов: футболки, шорты, свитеры, платья, плащи, сандалии, рубашки, кроссовки, сумки, ботинки)
- **Умный подбор наряда** — выбирает предметы одежды по погодным условиям:
  - < 0°C → пальто, свитер, ботинки
  - 0–10°C → пальто или тёплый джемпер, свитер, ботинки
  - 10–20°C → лёгкий джемпер, кроссовки, свитер
  - \> 20°C → футболка, сандалии, шорты
  - Ветер > 30 м/с — предупреждение о куртке
  - Дождь → рекомендация зонта / непромокаемой одежды
- **Визуальный вывод** — отправляет картинку с тремя предметами одежды
